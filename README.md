# Holdr

Walk-in queue app for barbers and other walk-in shops. Customers check wait times from anywhere, join the queue on an iPad in the shop, and track their spot with a QR code. Barbers run their own queue from their phone.

This is the clickable demo: pretend data, stored in the browser only. No backend yet.

Screens: Live wait times · iPad check-in · Customer ticket · Barber phone (PIN, queue, no-show, shop settings).

QR codes are generated with [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT).
